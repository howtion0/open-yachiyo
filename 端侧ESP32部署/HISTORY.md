# 端侧方向贡献记录

本页记录 Open Yachiyo 端侧与低成本硬件方向的工作脉络。时间表示实际设计或验证阶段；本页于 2026-09-08 根据项目同期记录和贡献者确认整理，不表示该 Markdown 文件在对应日期已经进入 GitHub。

## 2026-02：早期实时交互设计

Howtion 在项目早期参与低成本硬件上的用户友好实时语音交互逻辑设计，关注点包括：

- 将 Agent、ASR 和 TTS 等高负载能力留在主机或服务端；
- 端侧只接收动作、表情、视线和口型等轻量控制事件；
- 网络波动时保持本地待机、眨眼和触摸反馈；
- 让音频播放、口型驱动与角色动作通过事件解耦；
- 为后续 MCU、桌面宠物和专用显示终端保留统一接口。

原工作电脑更换后，本地 Git 对象没有保留下来，因此早期参与时间通过本页和带说明的重建提交补录。重建提交保留早期作者日期，同时使用实际整理日期作为提交者日期，以区分“工作发生时间”和“进入当前仓库时间”。

## 2026-09：ESP32-S3 实机验证

在 Waveshare ESP32-S3-Touch-AMOLED-1.8 V2 上完成 Live2D 实时运行验证：

- `.moc3` 模型在端侧逐帧计算，没有离线烘焙成视频；
- RGB565+A8 纹理和定点软件光栅适配 MCU 内存与带宽；
- 双核半屏并行、异步 LCD DMA 和 PSRAM 双缓冲稳定运行；
- 224×184 内部画布通过整数滤波放大到横屏 448×368；
- 触摸与 BOOT 按钮可以触发动作，无输入时保持待机；
- 轻量消锯齿版本实测约 6.9 FPS。

实现源码、模型素材和私有构建系统不随本目录公开；公开内容限于板型、烧录、运行原理、性能数据和跨板移植边界。
